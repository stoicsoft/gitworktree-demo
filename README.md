# Worktree Demo

A small playground for testing 1DevTool's git worktree feature.

## What's here

- A toy CLI that prints greetings
- A few branches to experiment with
- Just enough commit history to make the graph interesting

## Branches

- `main` — stable
- `feat/auth` — work-in-progress auth module
- `feat/api` — new HTTP endpoints
- `fix/typo` — small fix

Try creating worktrees for each branch and watch the colors light up.
